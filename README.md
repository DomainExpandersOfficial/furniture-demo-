# Sharma Enterprises - Bespoke Solid Wood Furniture & Living

A high-converting, luxury D2C furniture landing page built for **Sharma Enterprises** (Master Carpenter Ramcharan Sharma & Sons, Est. 1998, Kirti Nagar Lakkar Mandi, New Delhi). Inspired by the minimalist aesthetic of **Three Sixty (threesixty.life)**.

## ✨ Features

- **Minimalist Luxury D2C Aesthetic**: Clean typography with *Playfair Display* serif headings and *Plus Jakarta Sans* UI, rich cream & espresso palette with subtle brass/gold accents.
- **Announcement Ticker**: Dynamic cycling atelier ticker with navigation arrows.
- **Panoramic Collection Hero**: High-impact editorial hero with quick-action CTA buttons.
- **Interactive Pill Filters**: Category filters (Living, Dining, Bedroom, Mandir, Balcony, Doors, Study) with instant client-side rendering.
- **Ready in 7–12 Days Quick-Ship Switch**: Interactive toggle to filter fast-turnaround pieces.
- **Borderless Three Sixty Product Cards**: Square 1:1 image containers, top-left craftsmanship badges, rating displays, and direct WhatsApp inquiry integration.
- **Quick-View Inspection Modal**: Detailed wood species specifications, workshop dimensions, and direct booking actions.
- **Bespoke Atelier Section**: Custom furniture ordering where clients can share Pinterest/Instagram references via WhatsApp for upfront estimates within 2 hours.
- **The Atelier Process**: 4-step craft timeline showcasing timber selection, doorstep inching, raw frame workshop inspection, and white-glove placement.
- **Transparent Workshop Pricing Guide**: Log cubic footage rates and honest carpentry wage transparency.
- **Free In-Home Measurement Booking**: Zero-obligation doorstep consultation form with instant WhatsApp notification.
- **Customer Voices & FAQs**: Real Delhi NCR client experiences and answers to common queries.
- **Full Bilingual Support**: One-click instant switching between English and Hindi (`🌐 हिन्दी` / `🌐 English`).

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS3**: Custom design tokens, responsive CSS grid, flexbox, smooth micro-interactions.
- **Vanilla JavaScript**: Lightweight, modular state management, dynamic filtering, modal engine, and multilingual dictionary.
- **Zero Heavy Dependencies**: Loads instantly with high performance and zero build-step overhead.

## 🚀 Getting Started

To run locally:
```bash
# Using Python
python -m http.server 3000

# Or using Node.js
npx serve .
```

Open `http://localhost:3000` in your browser.
